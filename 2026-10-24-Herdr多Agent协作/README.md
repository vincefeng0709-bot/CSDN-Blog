# Herdr 多 Agent 协作文章归档

## 阅读入口

- [正文与本地图片版](article.md)：适合 GitHub 阅读，保留相对图片路径。
- [CSDN 发表稿](article.csdn.md)：图片已替换为用户上传并经核对的 CSDN 地址。
- [发布准备与状态](publish.md)：标题、摘要、标签、检查项。
- [资料来源](references.md)：官方资料对应结论、版本与图片来源说明。
- [验证记录](verification.md)：资料审校、图文验证及未执行的实验边界。
- [主控提示词](code/controller-prompt.txt)：与正文中的建议模板一致。

## 文件范围

`images/` 保存官方配图、图片来源记录及用户补充的封面。`code/` 保存资料收集、图文预览和平台图片核验的辅助脚本；它们不是已经运行验证过的 Herdr 编排器。`research/` 保存查阅时的资料文本、引用台账、版本和抓取记录；外部资料的权利归原权利人，适用条款与来源参见相应记录。

HTML 和 ZIP 是方便离线审阅的生成文件，不是运行截图或实验产物；CSDN 导入使用 `article.csdn.md`，不使用 HTML 或 ZIP。
