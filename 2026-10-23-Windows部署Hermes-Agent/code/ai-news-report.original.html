10.20

DeepSeek 全面开源生产级推理框架 DeepInfer

热度 ★★★★★

DeepSeek 以 Apache 2.0 协议开源支撑线上服务的推理框架 DeepInfer，并同步开源 Token 编解码组件 deepseek-recipe（MIT）。官方罕见披露运营数据：单集群每天服务 155 万亿 token、每 GPU 小时收入约 38 美元。框架集成投机解码（DSpark）、有界重放等优化，同时兼容英伟达 Blackwell（SM100）与华为昇腾 950，被视为对国产算力生态的重要支持。

来源：第一财经 · Concitech AI 日报 · 钛媒体

MiniMax 发布 M3.1 Flash：揭晓"太空兔"真身，Agent 成本降七成

热度 ★★★★☆
